# Python Practice

This repository contains my Python practice programs, coding questions, and problem-solving exercises.

It includes a wide range of programs covering different types of problems, from number and digit operations to strings, lists, functions, patterns, and logical challenges. The repository also contains the Python cache and compiled files generated while running the programs.

## What's Included

The repository contains programs and questions related to:

* Number and digit-based problems
* Prime number programs
* Armstrong numbers
* Factorial
* LCM and GCD
* Digit counting
* Digit sum and digit operations
* Number reversal and palindrome problems
* Strings and string operations
* Lists and list-based problems
* Tuples, sets, and dictionaries
* Functions and built-in functions
* Loops and conditional statements
* Pattern programs
* Mathematical problems
* Logical and problem-solving questions
* Different approaches to solving programming problems

## Python Files

The main programs are written in Python and are stored as `.py` files. Each program focuses on a particular question, concept, or problem-solving approach.

As the repository grows, new programs and questions are added regularly.

## Cache and Compiled Files

The repository may also contain files and folders generated automatically by Python while running the programs, including:

* `__pycache__/` folders
* `.pyc` compiled Python files

These files are generated by Python for caching and faster execution of imported modules.
